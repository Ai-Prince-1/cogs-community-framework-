# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.5.1] - 2026-11-06

### Changed
- Renamed the framework to **Circle of Good Samaritans** (was Circle of Good Stewards) across all documents. The Steward *role* and the value of stewardship keep their names.
- README: complete table of contents, Quick Start, how to propose changes, license section.
- Brand assets page rewritten as a clean brand guide.

### Added
- Filled meeting templates: Weekly Gathering, Season Opening, Season Review (Season Summary).
- Full CC BY-SA 4.0 license text, so GitHub recognizes the license.

### Fixed
- Eight broken links in the Circle Launch and Conflict Resolution playbooks.

## [0.5.0] - 2026-06-12

### Added
- Initial framework structure with core documents
- Manifesto and Handbook (v0.5)
- Constitution governance rules
- Anti-cult safeguards documentation
- Glossary of key terms
- Four core roles: Facilitator, Steward, Scribe, Bridge
- Meeting formats and templates
- Community playbooks including circle launch guide
- RFC process for community proposals
- Branding guidelines

### Documentation
- Comprehensive README with "Start Here" section
- Contributing guidelines
- License (CC BY-SA 4.0)
